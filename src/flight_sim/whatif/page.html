Jarvis gets its aerodynamics from a table made by RASAero II, which RASAero calculates from its own copy of the rocket (the .CDX1 file). This compares that copy with the current OpenRocket design. If they differ, Jarvis flies the current masses with the aerodynamics of the older shape until the table is regenerated with Update CSV (below).

About these predictions

Jarvis is the team's flight simulator, part of the flight_sim repository. It simulates the whole flight of the OpenRocket design in six degrees of freedom, from the launch rail to landing, using the aerodynamic table from RASAero II. VISION replays the same simulated flight in 3D. The OpenRocket lines are OpenRocket's own simulation of the same design, for comparison. If the two disagree by a lot, find out why before relying on either.

  • Motor: the newest thrust curve (.eng or .rse) in the rocket's thrust-curve folder.
  • Descent: the OpenRocket design has no parachutes yet, so Jarvis uses the Sol Invictus recovery system as a placeholder. OpenRocket's descent results are not shown for the same reason.
  • Not modeled: fin flutter, structural loads on the fins and rail buttons, and roll.
  • When to regenerate the RASAero table: after a large shape change, such as a fin dimension changing by about 25% or more, a different number of fins, a new nose shape or body diameter, or adding a boat tail.

Update CSV: regenerate the RASAero table

Use this after the rocket's shape changes. It runs RASAero II on the current design, converts the results into the aerodynamic table Jarvis uses, re-runs Jarvis and publishes the update. You need a Windows computer with RASAero II, a copy of the dynamics repository and flight_sim installed.

2. Run RASAero at every angle of attack

In OpenRocket, export the current design to RASAero (File → Export As → RASAero II) over rasaero.CDX1, and open that file in RASAero II. Click inside the RASAero window, return here and click Create the 31 RASAero files. Don't use the keyboard or mouse until the page says Finished. To stop early, move the mouse to a corner of the screen.

Before it starts, the helper checks the file against the OpenRocket design. If it has to correct the file, it stops without typing anything: open the corrected file in RASAero (File → Open) and click the button again.

3. Update the table and publish

Converts the 31 RASAero results into the table and re-runs Jarvis for every launch condition. Then it commits and pushes the new table and rasaero.CDX1 to GitHub, which rebuilds the site, and the helper closes.
